# Answer from vault evidence

Use the [Q&A playbook](../../../03_RESOURCES/Playbooks/Q%26A%20Against%20the%20Wiki.md) for orientation patterns. Start with relevant `_index.md` files and search terms from the question. Read the actual matching notes before citing them; an index title alone is not evidence.

Follow only the links needed to answer. Use raw sources when the compiled note is ambiguous or unsupported. Distinguish a note's creation date, the source's publication date, and the last time its claims were verified. A recently edited note does not prove the claim is current.

For each important conclusion, provide a path or link to the supporting note. Where sources disagree, state the competing claims and their scope. Prefer an explicit current decision over an older proposal when the evidence establishes that relationship. If no decision resolves the conflict, say so.

For drift-prone facts, verify against a current authoritative source when tools and the user's request allow it. Separate fresh external evidence from stored vault knowledge. If verification is unavailable or prohibited, identify the answer as historical or unverified. Do not fill evidence gaps with invented facts.

Answer in the thread unless the user requests a saved artifact. Read-only questions do not authorize new notes, index edits, or source-state changes. Close with only material uncertainty and missing evidence, rather than a generic research checklist.
